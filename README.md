## Descrição do Projeto
Este projeto foi desenvolvido utilizando os conceitos de
Programação Orientada a Objetos em Java.

O sistema representa uma pizzaria, contendo uma superclasse
abstrata chamada `Prato` e uma subclasse chamada `Pizza`.

Foram aplicados os seguintes conceitos:

- Classe Abstrata
- Herança
- Override
- Overload
- Encapsulamento
- Enums
- Construtores
- Getters
- Organização em pacotes
